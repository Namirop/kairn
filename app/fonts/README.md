# Polices locales

`Satoshi` n'est pas distribuée par Google Fonts. Les fichiers `.woff2` viennent
du CDN Fontshare (`cdn.fontshare.com`), sous **ITF Free Font Licence** : usage
personnel et commercial autorisé, y compris l'intégration web, sans redevance.

Graisses embarquées : 400 (texte), 500 (accentuation), 700 (titres d'interface).

Bricolage Grotesque et Geist Mono viennent de Google Fonts et sont chargées par
`next/font/google` — rien à stocker ici pour elles.
